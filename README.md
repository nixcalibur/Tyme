# Employee Time Tracking & Payroll Management System

A desktop application built with Java Swing for managing employee attendance records and calculating payroll based on working hours.

## Features

* Employee management (add/remove employees)
* Clock In / Clock Out functionality
* Automatic work duration calculation
* Payroll estimation based on hourly wage
* Attendance history tracking
* Multi-user support
* File-based data persistence
* Interactive table-based interface

## Technologies Used

* Java
* Java Swing
* Object-Oriented Programming (OOP)
* File I/O
* HashMap Data Structures
* Event-Driven Programming

## How It Works

1. Create or select an employee.
2. Record an **IN** timestamp when the employee starts work.
3. Record an **OUT** timestamp when the employee finishes work.
4. The system automatically calculates the duration worked.
5. Generate payroll estimates based on total accumulated hours.
6. Save employee records for future reference.
